Rockaden-temat är ett blocktema (FSE) som använder WordPress sidredigerare. Sidor kan organiseras hierarkiskt med förälder/barn-relationer för att skapa sektioner med sidnavigation.

The Rockaden theme is a block theme (FSE) that uses WordPress's site editor. Pages can be organized hierarchically with parent/child relationships to create sections with sidebar navigation.

Sidmallar

Page Templates

Standardsida

Default Page

Den vanliga sidmallen är en enkel innehållskolumn. Vill du ha sidomenyn (höger sida), lägg in blocket Sidebar Panel där du vill att den ska visas. Se "Sidomeny på vanliga sidor" i Inställningar för mer info.

The standard page template is a single content column. If you want the sidebar, insert the Sidebar Panel block where it should appear. See "Sidebar on regular Pages" in Settings for more info.

Sektionssida

Section Page

En tvåkolumnslayout med vänsternavigation och innehåll till höger. Navigeringen byggs automatiskt från sidans förälder/barn-hierarki. Perfekt för samlingar av relaterade sidor som "Om Rockaden" med undersidor.

A two-column layout with left sidebar navigation and content on the right. Navigation is built automatically from the page's parent/child hierarchy. Perfect for collections of related pages like "About Rockaden" with sub-pages.

Så här använder du: Skapa en föräldersida och lägg till undersidor. Välj mallen "Page (Section Nav)" i sidans inställningar. Alla barn-sidor får automatiskt navigering i vänsterkolumnen. Steg för steg: se guiden Bygg en sektionssida. How to use: Create a parent page and add child pages. Select the "Page (Section Nav)" template in the page settings. All child pages automatically get navigation in the left column. Step by step: see the Build a section page guide.

Att tänka på

Things to know

  • Bara en nivå. Sidomenyn visar roten och dess direkta undersidor. Barnbarn (undersidor till undersidor) visas inte.One level only. The side menu shows the root and its direct sub-pages. Grandchildren (sub-pages of sub-pages) are not listed.
  • Inga undersidor = ingen meny. Har rotsidan inga undersidor visas ingen sidomeny alls. Lägg till minst en undersida, eller välj en annan sidmall.No sub-pages = no menu. If the root page has no sub-pages, no side menu is shown at all. Add at least one sub-page, or use a different template.
  • Mallen måste sättas på varje sida i sektionen, både rot och undersidor. Glömmer du den renderas sidan utan sidomeny.The template must be set on every page in the section, root and sub-pages alike. If you forget it, the page renders without the side menu.
  • URL-strukturen. Med förälder satt blir undersidans adress /rotsida/undersida/. Det sköter WordPress automatiskt.URL structure. With a parent set, the sub-page's address becomes /root-page/sub-page/. WordPress handles this automatically.
  • Förälder, inte adress. En undersida hör till sektionen genom Parent – att adressen liknar de andras räcker inte.Parent, not address. A sub-page belongs to the section through its Parent setting – a similar-looking address is not enough.

Sidor som temat skapar

Pages the theme creates

Vid aktivering skapar temat ett antal startsidor, t.ex. Hem, Nyheter, Kalender och Träning. Innehållet är fritt redigerbart – temat skriver bara innehållet vid den första aktiveringen, aldrig därefter.

On activation the theme creates a set of starting pages, for example Hem, Nyheter, Kalender and Träning. Their content is freely editable – the theme writes the initial content on first activation only, never again.

Sidvisning

Page Display

Dölj sidtitel

Hide Page Title

Du kan dölja sidtiteln via metarutan Rockaden Display i sidredigeraren. Kryssa i "Hide page title" för sidor där titeln inte behövs (t.ex. startsidan).

You can hide the page title via the Rockaden Display meta box in the page editor. Check "Hide page title" for pages where the title isn't needed (e.g. the landing page).

Sidopanel

Sidebar

Blocket Sidebar ger samma kortpanel som syns bredvid nyheterna, fast med eget innehåll. Lägg in det på en sida och lägg sedan till ett Sidebar Card per panel. Varje kort är antingen en text med en valfri knapp, eller en bild som kan länkas – till exempel en partnerlogotyp.

The Sidebar block gives you the same card panel that appears beside the news, but with content of its own. Put it on a page, then add one Sidebar Card per panel. Each card is either text with an optional button, or an image that can be linked – a partner logo, for instance.

Eftersom innehållet ligger på sidan kan olika sidor ha olika kort – till exempel svenska kort på Hem och engelska på Home. Korten är avsiktligt begränsade till rubrik, text, bild och länk; du kan alltså inte lägga in vad som helst i en sidopanel, precis som i Utseende → Rockaden.

Because the content lives on the page, different pages can have different cards – Swedish ones on Hem and English on Home, for example. Cards are deliberately limited to a title, text, image and link; you cannot put arbitrary blocks in a sidebar panel, just as you cannot under Appearance → Rockaden.

Tips: Använd mönstret ”Page with sidebar” (fliken Mönster i blockinfogaren) så får du en färdig tvåspaltslayout med sidopanelen på plats – samma proportioner som nyhetssidan. Därefter är det vanliga block som du kan flytta om. Panelerna för nyheter och shopvaror styrs fortfarande av korten under Utseende → Rockaden. Tip: Use the “Page with sidebar” pattern (Patterns tab in the inserter) to get a ready-made two-column layout with the sidebar in place – the same proportions as the news view. After that it is ordinary blocks you can rearrange. The panels on news and shop pages are still driven by the cards under Appearance → Rockaden.

Shop-rutnät

Shop Grid

Temat tillhandahåller blocket Shop Items (under kategorin Rockaden i blockinfogaren). Det visar shopartiklar som ett rutnät — varje artikel har titel, bild, pris för icke-medlem och medlemspris, valfri köp-länk, lagerstatus (I lager / Slut i lager) och fri text för hur man beställer. Artiklarna hanteras under Shop Items i adminmenyn.

The theme provides the Shop Items block (under the Rockaden category in the inserter). It shows shop items as a grid — each item has a title, image, a non-member price and a member price, an optional buy link, a stock status (In stock / Out of stock), and free-text ordering instructions. Items are managed under Shop Items in the admin menu.
